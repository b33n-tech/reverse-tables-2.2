L'idée centrale
EntityForge inverse la logique des tableurs. Normalement tu remplis un tableau vide — ce qui crée une pression immédiate. Ici, tu définis d'abord la structure de tes données, puis tu remplis quand tu veux.
Entité = trame
Un bloc avec un nom et des propriétés. Chaque propriété = une colonne future. Exemple : entité Client avec Nom, Email, Téléphone → tableau à 3 colonnes, prêt à remplir.
Les deux espaces
⬡ Modèle — structure : crée des entités, des propriétés, des liaisons entre entités. C'est le schéma.
⊞ Données — saisie : remplis les tables ligne par ligne. Les colonnes liées (FK, Lookup, Rollup) se comportent intelligemment.
Créer une entité
1

Panneau droit : saisis un nom, choisis une couleur, indique le nombre estimé de lignes (modifiable plus tard).

2

Clique "+ Ajouter". Une carte apparaît sur le canvas. Déplace-la en glissant depuis l'en-tête coloré.

3

Renomme les propriétés en cliquant dessus. Change leur type via le menu déroulant (text, number, date…).

4

Clique "+ propriété" pour ajouter des colonnes. Survole une propriété pour faire apparaître le ✕ de suppression.

Navigation canvas
Pan : clic droit maintenu + glisser sur le fond, ou bouton du milieu.
Zoom : molette de la souris, ou boutons +/− en bas à gauche.
⊙ : recentre la vue à 100%.
Clic sur une entité dans le panneau droit : centre la vue sur sa carte.

FK Foreign Key — Référence
Une FK dit : "cette cellule pointe vers un enregistrement d'une autre table". C'est la liaison de base, le prérequis pour les Lookup et Rollup.
Exemple
Table Commandes, propriété Client → FK vers Clients.
Dans l'espace Données : la cellule devient un menu déroulant listant tous tes clients. Tu sélectionnes, c'est lié.
Comment créer
1

Sur la carte source (Commandes), clique ⇌ à droite de la propriété à lier.

2

Type = FK — Référence. Sélectionne l'entité cible (Clients). Clique Lier.

3

Une courbe bleue apparaît entre les cartes.

💡 Commence toujours par créer une FK avant d'ajouter un Lookup ou un Rollup.
LOOKUP Lookup — Valeur automatique
Un Lookup ramène automatiquement la valeur d'une propriété de la table liée. La colonne se remplit toute seule dès qu'une FK est sélectionnée. Elle est en lecture seule.
Exemple
Table Commandes, propriété Email client → Lookup vers la propriété Email de Clients, via la FK Client.
Choisis "Alice" → l'email s'affiche automatiquement en orange italique.
Comment créer
1

Il faut d'abord une FK dans cette table vers l'entité cible.

2

Clique ⇌ sur la propriété. Type = Lookup. Entité cible, propriété à afficher, et FK de liaison.

3

La courbe devient orange. Dans l'espace Données, la cellule se calcule seule.

ROLLUP Rollup — Agrégation
Un Rollup calcule une valeur agrégée à partir des lignes de la table liée qui pointent vers cet enregistrement. Comptage, somme, moyenne, min ou max.
Exemple
Table Clients, propriété Nb commandes → Rollup COUNT sur Commandes, via la FK Client dans Commandes.
Pour Alice : affiche automatiquement "3" si elle a 3 commandes.
Comment créer
1

La table cible (Commandes) doit avoir une FK pointant vers cette table (Clients).

2

Clique ⇌ sur la propriété dans Clients. Type = Rollup. Entité cible, opération, champ (pour SUM/AVG/MIN/MAX), FK dans la cible.

3

La courbe devient violette. La cellule se calcule en temps réel.

💡 COUNT ne nécessite pas de champ numérique — il compte juste les lignes correspondantes.
Exporter
Clique ↓ Exporter .zip. Choisis un ou plusieurs formats. Tu obtiens un .zip avec un fichier par entité — valeurs Lookup et Rollup résolues, pas d'index internes.
Formats
.csv — Excel, Google Sheets, tout outil
.json — Structuré + schéma complet, idéal API
.tsv — Variante du CSV, tab-separated
.md — Markdown table, pour la doc
Annuler (Undo)
Le bouton ↩ Annuler dans le header (ou Ctrl+Z) annule la dernière action structurelle : ajout/suppression d'entité, de propriété, création de liaison, déplacement de carte. L'historique conserve les 30 dernières actions.
Depuis l'espace Données
Toolbar de chaque table : + colonne ajoute une propriété sans quitter la vue données · + ligne ajoute une ligne · Supprimer supprime toute la table (avec confirmation).
